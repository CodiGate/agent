The Codigate agent is installed as {{ include "codigate-agent.fullname" . }} in namespace {{ .Release.Namespace }} ({{ .Values.replicaCount }} replica(s)).
It connects out to {{ .Values.edge | default "the edge in your ConfigMap" }}; it opens no ports in the cluster.

Check that it connects:

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "codigate-agent.fullname" . }} -f

Look for "tunnel connected". "tunnel disconnected, reconnecting" means the agent cannot reach the
edge or the token was rejected. The agent has no health endpoint, so the chart sets no probes.
